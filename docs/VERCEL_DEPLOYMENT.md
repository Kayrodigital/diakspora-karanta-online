# Déploiement Vercel

Le projet Vercel `diakspora-karanta-online` est relié au dépôt GitHub `Kayrodigital/diakspora-karanta-online`.

- Branche de production : `main`
- Chaque push sur `main` déclenche un déploiement de production.
- Les autres branches et pull requests déclenchent des déploiements de prévisualisation.
- Les variables Supabase sont configurées dans Vercel pour Production, Preview et Development.
